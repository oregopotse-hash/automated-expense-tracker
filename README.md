# Automated Expense Tracker

A Python and SQL expense-tracking application that automatically categorises expenses and generates spending summaries.

## Project Overview

The Automated Expense Tracker is a small financial-management application built with Python and SQLite.

The system allows users to record expenses, automatically assign categories based on the transaction description, store the information in an SQL database, and generate spending summaries.

## Features

- Add and store expenses
- Automatic expense categorisation
- SQLite database storage
- Spending summaries by category
- Total spending calculation
- Structured Python code
- SQL queries for storing and retrieving data

## Technologies Used

- Python
- SQLite / SQL
- Streamlit
- GitHub

## Example Categories

The application can categorise transactions into:

- Food
- Transport
- Bills
- Shopping
- Entertainment
- Other

## How It Works

1. A user enters an expense description and amount.
2. The application analyses the description.
3. A category is automatically assigned.
4. The transaction is stored in the SQLite database.
5. SQL queries are used to retrieve the stored information.
6. The application calculates spending summaries.

## Example

An expense such as:

`Petrol - R300`

is automatically categorised as:

`Transport`

An expense such as:

`Groceries - R450`

is automatically categorised as:

`Food`
